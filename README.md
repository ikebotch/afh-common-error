# AFH.Errors SDK

Initial scaffold for the AFH shared error handling SDK.

## Packages

- `AFH.Errors`: core abstractions and shared primitives for error handling.
- `AFH.Errors.AzureFunctions`: Azure Functions adapter built on top of `AFH.Errors`.
- `AFH.Errors.ApplicationInsights`: Application Insights adapter built on top of `AFH.Errors`.
- `AFH.Errors.Email`: email notification adapter built on top of `AFH.Errors`.
- `AFH.Errors.EntityFramework`: Entity Framework adapter built on top of `AFH.Errors`.

## Status

This repository currently contains the solution structure, package boundaries, and placeholder assemblies only. Behavioural implementation and real tests are intentionally deferred.
